    		 required

    		 required

    Returns:

    Type Description

    Name Type Description Default

    Mean-reversion speed.

    		 required
    mu float

    Long-term mean.

    		 required
    sigma float

    Volatility.

    		 required
    x0 float

    Initial value.

    		 required
    dt float

    Time step.

    		 required
    n_steps int

    Number of simulation steps.

    		 required
    seed int

    Random seed.

    		 required

    Returns:

    Type Description
    ndarray

    Simulated path of length n_steps + 1 (including x0).
